# Fullstack Learning Journey (Scrimba • Free Track)

## Overview
This repository documents my ongoing fullstack development journey using the free courses available on [**Scrimba.com**](https://scrimba.com/). Since the platform locks many of its [*Solo Projects*](Solo_Projects_Repos.md) behind the Pro subscription, I’ve built an alternative workflow that still lets me practice real‑world project building without losing momentum.

## Purpose of This Repo
The goal of this repository is to:

- Track my progress through Scrimba’s free fullstack curriculum  
- Reinforce each completed lesson with hands‑on coding exercises  
- Replace Scrimba’s Pro‑only Solo Projects with **AI‑generated project briefs** tailored to the lessons I’ve just finished  
- Build a portfolio of small, focused, incremental projects that reflect my growing skill set  

## How the Workflow Works
### 1. Complete a Scrimba Lesson  
I follow the free modules in the fullstack path — HTML, CSS, JavaScript, React, APIs, backend basics, and more.

### 2. Identify the Locked Solo Project  
Whenever a lesson ends with a Solo Project that requires a Pro subscription, I note the topic and the skills the project is meant to reinforce.

### 3. Generate a Replacement Project Using AI  
Instead of skipping the project, I ask AI to create:

- A project idea  
- A clear set of requirements  
- Constraints that match the difficulty of the lesson  
- Optional stretch goals  

This ensures I still get the practice Scrimba intended, even without Pro access.

### 4. Build the Project  
Each project gets its own repo, including:

- The AI‑generated brief (README.md) 
- My implementation (slight variance from AI-brief allowed to better allign with the scrimba lessons)

Currated links to the Solo Projects: [Solo_Projects_Repos.md](Solo_Projects_Repos.md)

## Why This Approach Works
- **Keeps the learning path intact** even without paid features  
- **Ensures consistent practice**, not just passive watching  
- **Builds a real portfolio** of progressively more advanced projects  
- **Teaches problem‑solving**, not just following tutorials  
- **Makes the curriculum more flexible**, because each project can be adapted to my interests  

## Long-Term Goal
By the end of the Scrimba fullstack path, this repo will serve as a complete record of my self‑directed learning — showing not only what I studied, but how I applied it through custom projects.
