# Links to Solo Project Repos
Whenever a lesson ends with a Solo Project that requires a Pro subscription, I note the topic and the skills the project is meant to reinforce.
Subsequently I generate a Replacement Project using AI, including:
 - A project idea
 - A clear set of requirements
 - Constraints that match the difficulty of the lesson
 - Optional stretch goals

This file curates the links to all my Replacement Solo Project repos for each Scrimba Course.
